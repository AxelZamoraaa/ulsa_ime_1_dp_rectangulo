# Receta: Área y perímetro de un rectángulo


1. MOSTRAR "Bienvenido a mi programa de rectangulo"
2. Mostrar "Escribe la base del rectangulo"
3. leer base
4. Mostrar "Escribe la altura del rectangulo"
5. Leer altura
6. Calcular area= base*altura
7. calcular perimetro= 2(base+altura)
8. mostrar "El area es: " + area"
9. Mostrar "El perimetro es:" + perimetro"
10. Mostrar "Fin del programa"
